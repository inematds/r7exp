# r7exp — explicativo visual do INEMA

Vídeo que **ensina opções**: um gráfico que funciona como mapa, uma mesma pessoa atravessando cada cenário, painéis que
entram na palavra falada e, no fim, o que você pode fazer. Sai um completo 16:9 e, dele, um reel por opção.

- Conceito e os pontos que originaram o formato: [CONCEITO.md](CONCEITO.md)
- Padrão (rascunho): [PADRAO.md](PADRAO.md)
- Referências: [pesquisa/REFERENCIAS.md](pesquisa/REFERENCIAS.md)
- Protótipo 1: `prototipo/zoologico/` — o caminho "zoológico humano" dos 5 futuros da IA.

Estado: **protótipo** (20/10/2026). Motor e modelo serão extraídos do protótipo aprovado.
